Welcome to HolyC-Unix!

"An idiot admires complexity, a genius admires simplicity." - Terry A. Davis

This operating system blends Unix philosophy (everything is a file,
standard input/output, pipes, hierarchical file system) with HolyC
and TempleOS principles (64-bit flat memory, JIT HolyC code execution,
16-color VGA palette, divine oracle).

Things to try:
- run `cat /etc/motd`
- run `god` to consult God's words
- run `cat /dev/god`
- run `cat /proc/tasks` to view kernel tasks
- run `cat /proc/uptime`
- run `ls -l /dev`
- run `ed note.txt` to write a text file
- run `holyc hello.HC` to execute HolyC code!
- run `holyc` to enter interactive HolyC REPL
- run `theme` to switch to TempleOS 16-color blue VGA mode!
